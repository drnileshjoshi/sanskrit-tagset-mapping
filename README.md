# Sanskrit Part-of-Speech Tagsets: Comparative Benchmark & Mapping Corpus

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC_BY_4.0-blue.svg)](https://creativecommons.org/licenses/by/4.0/)
[![Framework](https://img.shields.io/badge/Language-Sanskrit-orange.svg)]()
[![Funding: Ashtadashi](https://img.shields.io/badge/Funding-CSU_Ashtadashi_Scheme-green.svg)]()

This repository contains the dataset, mapping lexicons, and evaluation scripts for the comparative analysis of four major POS tagsets for Sanskrit: **IL-POST**, **BIS**, **Universal Dependencies (UD)**, and **The Sanskrit Library (TSL)**.
